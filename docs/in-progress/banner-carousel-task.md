# Banner 輪播組件開發任務清單

## 任務概述
根據提供的圖片規格，建立一個符合專案規範的 Banner 輪播組件，使用純 JavaScript 和 Vue 3 Composition API。

## 需求規格摘要

根據圖片描述：
- ✅ Banner 容器總是高度固定（不會因為 Banner 張數而影響）
- ✅ 隨 Device 寬度變化（不變形，此時高度會產生變化）
- ✅ Banner 最少有一張，二張以上時：
  - 一張時：Default 在第一張
  - 三張以上時：Default 在第一張，左右各有 Banner
  - 二張以上時：Default 在第一張
- ✅ 2 張以上時，Banner 需有自動滑動效果與可動滑動的功能
