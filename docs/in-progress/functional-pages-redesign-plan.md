**表單樣式：**
- 統一的輸入框樣式

**結果顯示：**
- 卡片式設計

## 風險管理

### 高風險頁面
- **Face API**: 複雜的視訊和 Canvas 操作
- **Web Authn / FIDO2**: 認證流程不能中斷

**應對策略：**
- 先在簡單頁面建立設計模式
- 謹慎測試每個改動
- 保留原始功能邏輯
- 分步驟實作和測試

### 中風險頁面
- **Web Cam**: 視訊相關功能
- **Frontend API Cache**: 快取邏輯

**應對策略：**
- 充分測試功能
- 確保樣式不影響功能

### 低風險頁面
- **Swagger Doc**: 主要是展示
- **Offline**: 簡單的狀態顯示

**應對策略：**
- 可以大膽設計
- 作為設計模式的參考
