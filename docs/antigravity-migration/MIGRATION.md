# Antigravity Migration Guide

> **Note**: This documentation and the accompanying tools were generated by **Gemini 3 Pro**.

This guide explains how to migrate this project and its AI Agent (Antigravity) state to a new computer.

## 📦 What is included?

The `antigravity_export.zip` contains:

1.  **Project Rules**: `.agent/`, `GEMINI.md`, `CLAUDE.md`, `.cursor/rules` (Coding standards & security policies)
2.  **Agent Memory**: `.gemini/antigravity/brain` (Task history, plans, artifacts)
3.  **Chat Logs**: `.gemini/antigravity/conversations` (Past conversation history)

## 🚀 How to Import on a New Machine

### Step 1: Clone the Project
On your new computer, clone the repository as usual:

```bash
git clone <your-repo-url>
cd parker-nuxt-lab
```

### Step 2: Transfer the Export File
Copy the `antigravity_export.zip` file (which you just likely generated) to the root of the project on the new computer.

### Step 3: Run the Import Script
We have provided scripts to automatically verify and place the agent's memory files in the correct system location.

#### macOS / Linux
Run the following path in the terminal:
```bash
chmod +x import_antigravity.sh
./import_antigravity.sh
```

#### Windows
Run with PowerShell:
```powershell
.\import_antigravity.ps1
```
*Note: You may need to run `Set-ExecutionPolicy Unrestricted -Scope Process` if script execution is disabled.*

**What this does:**
- Unzips the export.
- Identifies the agent state folder.
- Merges it into your current user's `~/.gemini` (macOS/Linux) or `%USERPROFILE%\.gemini` (Windows) directory.

### Step 4: Verify
Start the agent in the project. It should now have access to previous task history and coding rules.

---

## ⚠️ Notes

- **Overwriting**: The import script merges files. If you already have Antigravity data for *this specific project* on the new machine, it might be overwritten.
- **Project Files**: The script focuses on `~/.gemini`. It assumes you have the project files (`README.md`, etc.) from git. If you are transferring uncommitted changes, you might need to manually copy the project files if they differ from what's in git.
